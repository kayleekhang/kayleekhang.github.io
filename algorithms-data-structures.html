Algorithms and Data Structures Enhancement

Artifact Overview

The artifact used for this enhancement is my thermostat project from CS-350. The system reads temperature data from a sensor and determines behavior based on a selected mode (off, heat, or cool). The project originally relied on direct comparisons between temperature and setpoint to control system output.

Original Design

The original implementation used direct temperature comparisons tied to LED behavior. In heat mode, the system activated whenever the temperature was below the setpoint. In cool mode, it activated whenever the temperature was above the setpoint. While this approach functioned correctly, it created unstable behavior when the temperature fluctuated near the setpoint, resulting in rapid toggling between states. 

def updateLights(self):
    temp = floor(self.getFahrenheit())
    redLight.off()
    blueLight.off()

    if self.current_state.id == "heat":
        if temp < self.setPoint:
            redLight.pulse()
        else:
            redLight.on()

    if self.current_state.id == "cool":
        if temp > self.setPoint:
            blueLight.pulse()
        else:
            blueLight.on()

Enhanced Algorithm

To improve system stability, I implemented a hysteresis-based algorithm. Hysteresis introduces a buffer zone around the setpoint, preventing the system from rapidly switching states due to small fluctuations in temperature.

  • Heating starts only below a lower threshold
  • Cooling starts only above an upper threshold
  • A "hold" state prevents unnecessary transitions
def update(self):
    temp = floor(self.sensor.get_fahrenheit())

    if self.state == "heat":
        if temp <= self.setpoint - HYSTERESIS:
            action = "HEATING"
        elif temp >= self.setpoint:
            action = "IDLE"
        else:
            action = "HOLD"

    elif self.state == "cool":
        if temp >= self.setpoint + HYSTERESIS:
            action = "COOLING"
        elif temp <= self.setpoint:
            action = "IDLE"
        else:
            action = "HOLD"
    else:
        action = "OFF"

    self.db.log(self.state, temp, self.setpoint)
    self.serial.send(self.state, temp, self.setpoint)

    return temp, action

Key Improvements

  • Algorithm Stability: Reduced rapid toggling near the setpoint by introducing a buffer range.
  • State Management: Added an intermediate "HOLD" state to better control transitions.
  • Efficiency: Reduced unnecessary hardware state changes, improving overall system performance.
  • Real-World Application: Implemented logic commonly used in real thermostat systems.
